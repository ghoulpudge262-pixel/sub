# 🚀 VPN Subscription Generator

Beautiful VPN subscription generator with sleek dashboard.

## ✨ Features

- 🎨 Modern glassmorphism design
- 🌍 Flag emojis & beautiful server names
- 📊 Traffic & expiration tracking
- 🔒 VLESS Reality protocol support
- ⚡ Deploy on Vercel in 1 click

## 🚀 Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/vpn-sub-generator)

## 🔧 Setup

1. Fork this repo
2. Edit `data/servers.json` — add your servers
3. Edit `data/users.json` — add users
4. Deploy to Vercel

## 📱 Usage

- Subscription URL: `https://yourdomain.vercel.app/sub/USER_ID`
- Dashboard: `https://yourdomain.vercel.app/?id=USER_ID`
